# Bingofy

A dark, glassmorphic bingo maker you can actually play.

Create custom boards, tick cells live, save multiple cards locally, share the exact layout with friends, and sync multiplayer updates through Supabase.

## Stack

React + TypeScript + Vite + Supabase.

## Local development

```bash
npm install
npm run dev
```

## Deploy

Push to `main`. The included GitHub Actions workflow builds and deploys the site to GitHub Pages.
